# Summary
Replace the no-op `solveContacts` in `src/physics/contacts.js` with a sequential impulse solver: restitution and Coulomb friction, accumulated impulse clamping, Baumgarte or split-impulse penetration correction, speculative contact handling, settling damping and impact events for sound and haptics. Solver half of #5, developed in parallel with the collision detection half (#14).

# Specs
## Context
World, bodies and the fixed-timestep loop come from task #4 (`src/physics/`: `body.js` with `createBody`/`applyImpulse`/`invMass`/`invInertiaWorld`, `world.js` with `createWorld`, `world.events`, `FIXED_DT = 1/480`). Shapes come from task #3. `src/physics/contacts.js` currently holds a no-op `solveContacts(world, dt)` — replace it. `world.step` order is `integrateVelocities → solveContacts → integratePositions`; velocities are already gravity-integrated when the solver runs.

Contacts come from `world.contacts`, generated by `detectContacts` (task #14) and cleared each step. Until that half lands, read `world.contacts ?? []` and test against hand-crafted contacts. A contact is `{ a, b (body or null for box), surface: 'floor' | 'lid' | 'wall' | 'die', point (world vec3), normal (unit, from b toward a; for box contacts the inward plane normal), depth (positive = penetration, negative = gap) }`.

## Files
- `src/physics/contacts.js`: sequential impulse solver. Do not touch `world.js`, `collision.js` or any other #4 file — replace only the contents of `contacts.js`.
  - Precompute per contact effective mass for normal and two tangents, using `invMass` and `invInertiaWorld`.
  - Restitution: target `-e · v_n` only when approach speed > `RESTITUTION_THRESHOLD` (0.1 m/s). `RESTITUTION_BOX = 0.3` (box contacts, b = null), `RESTITUTION_DIE = 0.4` (die-die).
  - Coulomb friction, two tangent directions, clamped by `μ · accumulated normal impulse`. `FRICTION_BOX = 0.4`, `FRICTION_DIE = 0.3`.
  - Accumulated impulse clamping (normal ≥ 0), `SOLVER_ITERATIONS = 10`.
  - Penetration correction: Baumgarte bias `β = 0.2`, `SLOP = 0.0002` m, or split impulses. Speculative contacts (negative depth) allow `v_n` up to `-depth/dt` and get no bias.
  - Rolling resistance or an equivalent so dice settle instead of rocking forever: a small angular damping while in contact is fine.
  - Impact events: for each body pair (or body/surface) whose approach speed is above `EVENT_MIN_SPEED` (0.05 m/s) in this step, push ONE event per pair and step to `world.events`: `{ a, b, surface, point, speed (approach normal speed, m/s), impulse (summed normal impulse, N·s) }`. The sound and haptics task (#9) reads these events after each frame.
  - Constants are exported from the module that uses them.

## Tests (`src/physics/contacts.test.js`, solver in isolation with hand-crafted contacts on minimal world objects)
- Single box-floor contact on a falling body: after solving, the approach speed resolves to the restitution target (`-e·v_n` above the threshold, 0 below).
- Friction: a sliding body decelerates and the tangent impulse never exceeds `μ · accumulated normal impulse`.
- Accumulated impulses: the normal impulse never goes negative; an iterated resting contact stays stable (no drift, no growing impulse).
- Speculative contact (negative depth): approach speed up to `-depth/dt` is allowed and no Baumgarte bias applies.
- Two equal-mass bodies in a head-on die-die contact resolve symmetrically.
- Events: an approach above `EVENT_MIN_SPEED` pushes exactly one event per pair per step with `speed` and summed normal `impulse`; a resting contact pushes none.
